# Приложение «Анализатор банковских операций»

Программа для анализа транзакций пользователей, генерации отчетов, а также получения актуальных курсов валют и акций через внешние API.

## Запуск проекта
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Подложите файл с данными в `data/operations.xlsx`.
3. Запустите приложение через `src/main.py`.

## Тестирование
Для запуска тестов с отчетом о покрытии выполните:
```bash
pytest --cov=src tests/
```
